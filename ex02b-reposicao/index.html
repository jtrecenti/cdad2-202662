Montar o gráfico na ordem certa

Todo gráfico é o fim de uma sequência: primeiro a tabela chega no formato certo, depois o gráfico é desenhado. Neste projeto as duas partes vêm em blocos soltos, e o trabalho é colocar na ordem que responde à pergunta.

  1. Carregar o ambiente (o Python roda no seu navegador).
  2. Ler a pergunta e olhar o gráfico que precisa ser produzido.
  3. Colocar os blocos nas duas esteiras, com o botão →: preparar os dados (pandas) e montar o gráfico (plotnine).
  4. Rodar. O gráfico que aparece é o do seu código, inclusive quando está errado.
  5. Comparar os dois gráficos e ajustar. São 4 desafios, e dá para seguir para o próximo mesmo sem acertar.
Como conta a nota: cada um dos quatro desafios vale 2,5, somando 10. Cada tentativa errada desconta 0,25, e conta tanto o código que dá erro quanto o que roda mas produz outro gráfico. O placar no alto do desafio mostra a nota em tempo real.

No fim: o app registra os blocos que você usou, a nota, e gera um arquivo .py com os quatro códigos, para você guardar.
Projeto individual. Alguns blocos não devem ser usados: escolher o errado faz parte, e o app explica o que aquele bloco fez.
