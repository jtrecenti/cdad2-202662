Distribuições comuns

Diversos fenômenos podem ser explicados por algumas variáveis aleatórias conhecidas e que já foram amplamente estudadas.

Discretas e contínuas

discreta

Assume valores separados, que dá para listar: 0, 1, 2, 3.

Quase sempre é uma contagem.

\(P(X = 3)\) faz sentido, e o gráfico é de barras.

contínua

Assume qualquer valor de um intervalo: 412 dias, ou 412,7, ou 412,73.

Quase sempre é uma medida.

Aqui a probabilidade é área, e a pergunta é por faixa. O gráfico é uma curva.

É a mesma classificação de variáveis da aula 2, agora aplicada ao que a probabilidade descreve.

As contínuas

Exponencial

curva(x => taxa_exp * Math.exp(-taxa_exp * x), 0, 40, "dias até o próximo despacho")
viewof taxa_exp = Inputs.range([0.05, 0.6], {value: 0.15, step: 0.05, label: "taxa (por dia)"})
descreve o tempo de espera até o próximo acontecimento
parâmetro \(\lambda\), a taxa
média \(E(X) = 1/\lambda\)
variância \(Var(X) = 1/\lambda^2\)
exemplo dias até o próximo despacho no processo

Repare na forma: muitos casos rápidos e uma cauda longa. É o desenho do tempo de tramitação de quase todo tribunal.

Normal

curva(x => Math.exp(-0.5 * Math.pow((x - mu_norm) / sd_norm, 2)) /
           (sd_norm * Math.sqrt(2 * Math.PI)), 0, 120, "dias até o laudo pericial")
viewof mu_norm = Inputs.range([40, 80], {value: 60, step: 1, label: "média (μ)"})
viewof sd_norm = Inputs.range([4, 20], {value: 8, step: 1, label: "desvio padrão (σ)"})
descreve a soma de muitas causas pequenas e independentes
parâmetros \(\mu\) e \(\sigma\)
média \(E(X) = \mu\)
variância \(Var(X) = \sigma^2\)
exemplo dias até o laudo pericial ficar pronto

Por que a normal aparece tanto

a razão

Quando o resultado é a soma de muitas causas pequenas e independentes, ele tende a ficar normal, não importa como cada causa se distribui.

O tempo de um laudo é a soma de dezenas de etapas. A altura de uma pessoa é a soma de muitos genes. Nenhum dos dois é normal por escolha de ninguém.

e onde ela não serve

Dinheiro quase nunca é normal. Valores de indenização, honorários e custas são assimétricos: um piso em zero, muitos casos pequenos e alguns enormes. A normal é simétrica e não descreve isso.

Esse resultado tem nome, teorema central do limite, e é o assunto da aula 11.

Do tipo da variável para a distribuição

tipo da variável exemplo na base distribuição
categórica, dois valores houve acordo? Bernoulli
categórica, três ou mais regime: fechado, semiaberto, aberto multinomial
numérica discreta, com teto quantos dos 10 recursos foram providos binomial
numérica discreta, sem teto ações novas por dia Poisson
numérica contínua, espera dias até o despacho exponencial
numérica contínua, simétrica dias até o laudo normal

São os mesmos tipos de variável da aula 2. O que muda é que agora cada um tem um modelo por trás, com parâmetros que dão a média e a variância.

Resumo

o que fica

  1. Contagem vira barra e é discreta; medida vira curva e é contínua.

  2. Categórica de dois valores é Bernoulli; de mais valores, multinomial.

  3. Contagem com teto é binomial; sem teto é Poisson.

  4. Tempo de espera é exponencial, com cauda longa. Soma de muitas causas é normal, e dinheiro quase nunca é.

  5. Cada uma tem parâmetros, e deles saem a média e a variância.

ns = "http://www.w3.org/2000/svg"

moldura = function (largura, altura) {
  const svg = document.createElementNS(ns, "svg");
  svg.setAttribute("viewBox", `0 0 ${largura} ${altura}`);
  // tamanho fixo, e nao 100%: o slide tem largura fixa, e um SVG elastico
  // dentro de um item flex empurra a coluna vizinha para fora da tela.
  svg.setAttribute("width", largura);
  svg.setAttribute("height", altura);
  svg.style.display = "block";
  svg.style.margin = "0 auto";
  return svg;
}

eixo_x = function (svg, L, A, m, rotulo) {
  const linha = document.createElementNS(ns, "line");
  linha.setAttribute("x1", m); linha.setAttribute("x2", L - m);
  linha.setAttribute("y1", A - m); linha.setAttribute("y2", A - m);
  linha.style.stroke = "var(--texto-fraco)";
  svg.appendChild(linha);
  const t = document.createElementNS(ns, "text");
  t.setAttribute("x", L - m); t.setAttribute("y", A - 4);
  t.setAttribute("text-anchor", "end");
  t.setAttribute("font-size", "15");
  t.style.fill = "var(--texto-fraco)";
  t.textContent = rotulo;
  svg.appendChild(t);
}

// Barras para as discretas. O teto vertical e PARAMETRO, e nao automatico: com
// escala automatica, aumentar o n reescala o eixo junto e da a impressao de que
// nada mudou. Nas que mudam muito de forma o teto e 0,45; na Bernoulli e na
// multinomial, que tem poucas barras e altas, e 1.
barras = function (valores, probs, rotulo, teto) {
  const L = 1120, A = 252, m = 40;
  const svg = moldura(L, A);
  const larg = (L - 2 * m) / valores.length;
  valores.forEach(function (v, i) {
    const h = Math.min(probs[i] / teto, 1) * (A - 2 * m - 14);
    const r = document.createElementNS(ns, "rect");
    r.setAttribute("x", m + i * larg + larg * 0.14);
    r.setAttribute("y", A - m - h);
    r.setAttribute("width", larg * 0.72);
    r.setAttribute("height", Math.max(h, 0));
    r.setAttribute("fill", "#12996f");
    svg.appendChild(r);
    // rotula so o que cabe, senao vira uma mancha de numeros
    if (valores.length <= 21 && (valores.length <= 12 || i % 2 === 0)) {
      const t = document.createElementNS(ns, "text");
      t.setAttribute("x", m + i * larg + larg / 2);
      t.setAttribute("y", A - m + 17);
      t.setAttribute("text-anchor", "middle");
      t.setAttribute("font-size", "14");
      t.style.fill = "var(--texto-fraco)";
      t.textContent = v;
      svg.appendChild(t);
    }
  });
  eixo_x(svg, L, A, m, rotulo);
  return svg;
}

// Curva para as continuas, com a area pintada: e a area que e a probabilidade,
// e o slide inteiro depende de a turma ver isso.
curva = function (dens, x0, x1, rotulo) {
  const L = 1120, A = 252, m = 40;
  const svg = moldura(L, A);
  const px = v => m + ((v - x0) / (x1 - x0)) * (L - 2 * m);
  let ymax = 0;
  for (let i = 0; i <= 400; i++) ymax = Math.max(ymax, dens(x0 + (i / 400) * (x1 - x0)));
  const py = d => A - m - (d / (ymax * 1.12)) * (A - 2 * m - 10);

  let area = `M ${px(x0)} ${A - m}`;
  for (let i = 0; i <= 400; i++) {
    const v = x0 + (i / 400) * (x1 - x0);
    area += ` L ${px(v)} ${py(dens(v))}`;
  }
  area += ` L ${px(x1)} ${A - m} Z`;
  const p = document.createElementNS(ns, "path");
  p.setAttribute("d", area);
  p.setAttribute("fill", "#bfe6d5");
  svg.appendChild(p);

  let linha = "";
  for (let i = 0; i <= 400; i++) {
    const v = x0 + (i / 400) * (x1 - x0);
    linha += (i ? " L " : "M ") + px(v) + " " + py(dens(v));
  }
  const l = document.createElementNS(ns, "path");
  l.setAttribute("d", linha);
  l.setAttribute("fill", "none");
  l.style.stroke = "var(--texto)";
  l.setAttribute("stroke-width", 2.2);
  svg.appendChild(l);

  eixo_x(svg, L, A, m, rotulo);
  const passo = (x1 - x0) / 6;
  for (let i = 0; i <= 6; i++) {
    const v = x0 + i * passo;
    const t = document.createElementNS(ns, "text");
    t.setAttribute("x", px(v)); t.setAttribute("y", A - m + 17);
    t.setAttribute("text-anchor", "middle");
    t.setAttribute("font-size", "14");
    t.style.fill = "var(--texto-fraco)";
    t.textContent = Math.round(v);
    svg.appendChild(t);
  }
  return svg;
}
