Exemplo 1

Uma pesquisadora quer saber quanto tempo 8.505 recursos criminais do TJSP levaram, em média, da distribuição ao julgamento. Para saber o tempo de cada recurso, é preciso abrir o processo e ler as datas. Por isso, ela sorteia 100 recursos, lê cada um e calcula a média deles: 2,8 anos. Mas o que ela quer mesmo saber é o tempo médio dos 8.505.

O parâmetro mora na população; a estimativa mora na amostra.

o nome disso

Distribuição amostral: a distribuição das estimativas quando o sorteio é repetido muitas vezes, sempre com o mesmo tamanho de amostra.

O gráfico do painel não é a distribuição do tempo dos recursos: é a distribuição da média que sai da conta de cada um. A média da amostra é uma variável aleatória, como as da aula 9.

Três propriedades

1 · centro

O valor esperado da média amostral é a média populacional. As médias da sala se espalham em torno da linha vermelha, sem puxar para um lado.

2 · forma

A média amostral tem distribuição aproximadamente normal, mesmo com o tempo dos recursos sendo torto. Quem garante é o teorema central do limite.

3 · incerteza

A incerteza da média amostral se chama erro-padrão: é o desvio-padrão dos dados da amostra dividido por \(\sqrt{n}\). Ou seja, ela encolhe conforme a amostra cresce.

Teorema central do limite

o enunciado

Para amostras grandes o bastante, a média de uma amostra aleatória tem distribuição aproximadamente normal, centrada na média da população, seja qual for a forma da população.

Erro-padrão

erro-padrão

\[\text{EP} = \frac{\text{DP}}{\sqrt{n}}\]

DP é o desvio-padrão dos dados da amostra, e \(n\) é o tamanho dela.

amostra erro-padrão, com DP de 1,87 ano
25 recursos 1,87 ÷ 5 ≈ 0,37 ano
100 recursos 1,87 ÷ 10 ≈ 0,19 ano
400 recursos 1,87 ÷ 20 ≈ 0,09 ano

Intervalo de confiança

Na vida real há uma amostra só. O intervalo leva a incerteza junto com a estimativa: em vez de um número, uma faixa.

Construção

intervalo de confiança para a média

\[\text{média} \pm z \times \frac{\text{DP}}{\sqrt{n}}\]

Com 95% de confiança, \(z = 1{,}96\). De onde vem esse número é o próximo slide.

viewof conf = Inputs.range([0.5, 0.9999], {value: 0.95, step: 0.0001, label: "confiança"})
curvaNormal(conf)

Pelo teorema central do limite, a média da amostra é aproximadamente normal em torno da média populacional. Numa normal, 95% da área fica a menos de 1,96 erros-padrão do centro: esse é o \(z\). Mais confiança pede um \(z\) maior e um intervalo mais largo; 100% de confiança exigiria um intervalo infinito.

o que significa 95%

A confiança é propriedade do procedimento: repetido muitas vezes, ele acerta em cerca de 95% delas. O parâmetro é fixo, e cada intervalo o contém ou não o contém.

Qual leitura do intervalo é a correta?

A frase certa

incorreto

“Há 95% de probabilidade de o tempo médio dos 8.505 recursos estar entre 2,4 e 3,2 anos.”

A média dos 8.505 não é sorteada. Ela já é o que é.

correto

“O tempo médio estimado é de 2,8 anos, com intervalo de confiança de 95% entre 2,4 e 3,2 anos.”

É a mesma troca de condicionais da aula 7: a chance de o procedimento acertar não é a chance de a média estar dentro deste intervalo.

Exercício 2

em duplas, 15 minutos

Um escritório sorteou 100 das 2.400 apelações cíveis que acompanhou em 2025 e mediu o tempo até o julgamento: média de 1,8 ano, desvio-padrão de 1 ano.

a) Aponte a população, a amostra, o parâmetro e a estimativa.

b) Outra equipe sorteia outras 100 dessas apelações e encontra 2 anos. Alguém errou? O que muda de uma amostra para a outra, e o que fica igual?

c) Calcule o erro-padrão.

d) Escreva o intervalo de 95% e a frase que vai no relatório.

e) Quantas apelações seriam necessárias para a margem cair pela metade?

f) O sócio lê o relatório e conclui: “então 95% das nossas apelações são julgadas entre 1,6 e 2 anos”. Está certo?

Resumo

cinco ideias

  1. Parâmetro descreve a população e é fixo; estimativa vem da amostra e muda a cada sorteio.

  2. A distribuição das estimativas de muitas amostras é a distribuição amostral: foi o gráfico do painel.

  3. Teorema central do limite: a média da amostra é aproximadamente normal, em torno da média da população, seja qual for a forma da população.

  4. Erro-padrão \(= \text{DP}/\sqrt{n}\), e o intervalo é \(\text{média} \pm z \times \text{EP}\), com \(z = 1{,}96\) para 95%.

  5. Os 95% são do procedimento: foi a proporção de intervalos da sala que pegou a média dos 8.505.

populacao = ({
  "assimétrica": () => Math.min(1, -Math.log(1 - Math.random()) / 5),
  "duas modas": () =>
    Math.random() < 0.5
      ? 0.2 + (Math.random() - 0.5) * 0.16
      : 0.8 + (Math.random() - 0.5) * 0.16,
  "uniforme": () => Math.random(),
  "moeda": () => (Math.random() < 0.5 ? 0 : 1)
})

media_teorica = ({
  "assimétrica": 0.2,
  "duas modas": 0.5,
  "uniforme": 0.5,
  "moeda": 0.5
})

medias = function (n, forma) {
  const f = populacao[forma];
  let s = 0;
  for (let i = 0; i < n; i++) s += f();
  return s / n;
}

rotulo = function (texto) {
  const d = document.createElement("div");
  d.style.cssText = "font-size:.55em;font-weight:600;letter-spacing:.08em;text-transform:uppercase;color:var(--texto-fraco);margin:.2rem 0 0";
  d.textContent = texto;
  return d;
}

histograma = function (valores, marca, altura, cor) {
  const L = 900, A = 300, m = 30, faixas = 50;
  const contagem = new Array(faixas).fill(0);
  for (const v of valores) {
    const i = Math.min(faixas - 1, Math.max(0, Math.floor(v * faixas)));
    contagem[i] += 1;
  }
  const topo = Math.max(...contagem);
  const larg = (L - 2 * m) / faixas;
  const ns = "http://www.w3.org/2000/svg";
  const svg = document.createElementNS(ns, "svg");
  svg.setAttribute("viewBox", "0 0 " + L + " " + A);
  svg.setAttribute("width", "100%");
  svg.setAttribute("preserveAspectRatio", "none");
  svg.style.height = altura + "px";
  svg.style.display = "block";

  contagem.forEach(function (c, i) {
    const h = topo ? (c / topo) * (A - 2 * m) : 0;
    const r = document.createElementNS(ns, "rect");
    r.setAttribute("x", m + i * larg + 0.8);
    r.setAttribute("y", A - m - h);
    r.setAttribute("width", Math.max(1, larg - 1.6));
    r.setAttribute("height", h);
    r.setAttribute("fill", cor);
    svg.appendChild(r);
  });

  const eixo = document.createElementNS(ns, "line");
  eixo.setAttribute("x1", m);
  eixo.setAttribute("x2", L - m);
  eixo.setAttribute("y1", A - m);
  eixo.setAttribute("y2", A - m);
  eixo.setAttribute("stroke", "#8a8f98");
  svg.appendChild(eixo);

  const x = m + marca * (L - 2 * m);
  const linha = document.createElementNS(ns, "line");
  linha.setAttribute("x1", x);
  linha.setAttribute("x2", x);
  linha.setAttribute("y1", 4);
  linha.setAttribute("y2", A - m);
  linha.setAttribute("stroke", "#e50505");
  linha.setAttribute("stroke-width", 3);
  svg.appendChild(linha);

  return svg;
}

// Area da normal padrao entre -z e z e erf(z / raiz de 2). A aproximacao de
// Abramowitz e Stegun (7.1.26) erra menos que 1e-7, e o z sai por bissecao.
erf = function (x) {
  const s = Math.sign(x);
  const a = Math.abs(x);
  const t = 1 / (1 + 0.3275911 * a);
  const y = 1 - (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t
    - 0.284496736) * t + 0.254829592) * t * Math.exp(-a * a);
  return s * y;
}

zDaConfianca = function (c) {
  let lo = 0, hi = 6;
  for (let i = 0; i < 60; i++) {
    const meio = (lo + hi) / 2;
    if (erf(meio / Math.SQRT2) < c) lo = meio; else hi = meio;
  }
  return (lo + hi) / 2;
}

// Numero com virgula e sem zeros sobrando: 95 -> "95", 99.99 -> "99,99",
// 0.005 -> "0,005". Com confianca de 0,9999 o toFixed fixo mostrava "100%".
enxuto = function (v, casas) {
  return v.toFixed(casas).replace(/\.?0+$/, "").replace(".", ",");
}

curvaNormal = function (c) {
  const z = zDaConfianca(c);
  const L = 900, A = 300, m = 34, topo = 30;
  const px = (v) => m + ((v + 4) / 8) * (L - 2 * m);
  const pdf = (v) => Math.exp(-v * v / 2) / Math.sqrt(2 * Math.PI);
  const py = (d) => A - m - (d / 0.4) * (A - m - topo);
  const ns = "http://www.w3.org/2000/svg";
  const svg = document.createElementNS(ns, "svg");
  svg.setAttribute("viewBox", "0 0 " + L + " " + A);
  svg.setAttribute("width", "100%");
  svg.style.maxHeight = "330px";
  svg.style.display = "block";
  const el = (tag, attrs, texto) => {
    const n = document.createElementNS(ns, tag);
    for (const [k, v] of Object.entries(attrs)) n.setAttribute(k, v);
    if (texto) n.textContent = texto;
    svg.appendChild(n);
    return n;
  };

  let area = "M" + px(-z) + "," + py(0);
  for (let k = 0; k <= 120; k++) {
    const v = -z + (2 * z * k) / 120;
    area += "L" + px(v).toFixed(1) + "," + py(pdf(v)).toFixed(1);
  }
  area += "L" + px(z) + "," + py(0) + "Z";
  el("path", {d: area, fill: "#12996f", "fill-opacity": 0.35});

  let curva = "";
  for (let k = 0; k <= 240; k++) {
    const v = -4 + (8 * k) / 240;
    curva += (k ? "L" : "M") + px(v).toFixed(1) + "," + py(pdf(v)).toFixed(1);
  }
  el("path", {d: curva, fill: "none", stroke: "#8a8f98", "stroke-width": 3});
  el("line", {x1: m, x2: L - m, y1: py(0), y2: py(0), stroke: "#8a8f98", "stroke-width": 1.5});

  const f = (v, casas) => v.toFixed(casas).replace(".", ",");
  for (const s of [-1, 1]) {
    el("line", {x1: px(s * z), x2: px(s * z), y1: py(0), y2: py(pdf(z)) - 14,
                stroke: "#e50505", "stroke-width": 3});
    el("text", {x: px(s * z), y: py(0) + 26, "text-anchor": "middle", "font-size": 20,
                "font-weight": 700, fill: "#e50505"}, (s < 0 ? "-" : "+") + f(z, 2));
    // a cauda fica perto da borda: com z perto de 4, a 3,2 ela bateria no traco
    el("text", {x: px(s * 3.6), y: py(0.07), "text-anchor": "middle", "font-size": 17,
                fill: "#8a8f98"}, enxuto((1 - c) * 50, 3) + "%");
  }
  el("text", {x: px(0), y: py(0.16), "text-anchor": "middle", "font-size": 26,
              "font-weight": 700, fill: "#12996f"}, enxuto(c * 100, 2) + "% da área");
  el("text", {x: px(0), y: topo - 6, "text-anchor": "middle", "font-size": 19,
              fill: "#8a8f98"}, "z = " + f(z, 2) + " erros-padrão a partir do centro");
  return svg;
}

// O intervalo do slide de construcao, num eixo parado de 0 a 6 anos: mexer na
// media so desloca a barra, e mexer no DP, no n e na confianca muda a largura.
// O que passa do eixo e cortado na borda, com uma ponta de seta.
desenhaIC = function ({media, dp, n, conf}) {
  const z = zDaConfianca(conf);
  const ep = dp / Math.sqrt(n);
  const lo = media - z * ep, hi = media + z * ep;
  const L = 900, A = 250, m = 40, x0 = 0, x1 = 6, yb = 118, base = 178;
  const px = (v) => m + ((Math.min(x1, Math.max(x0, v)) - x0) / (x1 - x0)) * (L - 2 * m);
  const ns = "http://www.w3.org/2000/svg";
  const svg = document.createElementNS(ns, "svg");
  svg.setAttribute("viewBox", "0 0 " + L + " " + A);
  svg.setAttribute("width", "100%");
  svg.style.maxHeight = "280px";
  svg.style.display = "block";
  const el = (tag, attrs, texto) => {
    const no = document.createElementNS(ns, tag);
    for (const [k, v] of Object.entries(attrs)) no.setAttribute(k, v);
    if (texto) no.textContent = texto;
    svg.appendChild(no);
    return no;
  };
  const f = (v, casas) => v.toFixed(casas).replace(".", ",");

  el("line", {x1: m, x2: L - m, y1: base, y2: base, stroke: "#8a8f98", "stroke-width": 1.5});
  for (let v = x0; v <= x1; v++) {
    el("line", {x1: px(v), x2: px(v), y1: base, y2: base + 7, stroke: "#8a8f98", "stroke-width": 1.5});
    el("text", {x: px(v), y: base + 30, "text-anchor": "middle", "font-size": 19, fill: "#8a8f98"}, String(v));
  }
  el("text", {x: L - m, y: base + 58, "text-anchor": "end", "font-size": 17, fill: "#8a8f98"}, "anos");

  el("line", {x1: px(lo), x2: px(hi), y1: yb, y2: yb, stroke: "#12996f", "stroke-width": 9,
              "stroke-linecap": "butt"});
  for (const [v, lado] of [[lo, -1], [hi, 1]]) {
    const cortado = v < x0 || v > x1;
    const xp = px(v);
    if (cortado) {
      el("path", {d: `M${xp},${yb - 13} L${xp + lado * 16},${yb} L${xp},${yb + 13} Z`, fill: "#12996f"});
    } else {
      el("line", {x1: xp, x2: xp, y1: yb - 16, y2: yb + 16, stroke: "#12996f", "stroke-width": 4});
    }
  }
  el("circle", {cx: px(media), cy: yb, r: 9, fill: "#e50505"});

  const meio = Math.min(L - m - 170, Math.max(m + 170, px(media)));
  el("text", {x: meio, y: yb - 38, "text-anchor": "middle", "font-size": 30, "font-weight": 700,
              style: "fill: var(--texto)"}, `de ${f(lo, 2)} a ${f(hi, 2)} anos`);
  el("text", {x: L / 2, y: 30, "text-anchor": "middle", "font-size": 19, fill: "#8a8f98"},
     `EP = ${f(dp, 1)} ÷ √${n} = ${f(ep, 2)}   ·   z = ${f(z, 2)}   ·   margem = z × EP = ${f(z * ep, 2)}`);
  return svg;
}
